# App Support

Public support and privacy pages for apps published by JustPeca.

## Structure

- `/warefox/` — WareFox
  - `support.html`
  - `privacy.html`

More apps can be added as their own folders using the same structure.

## GitHub Pages

Publish from **main / (root)** in repository Settings → Pages.

Expected URLs:

- https://justpeca.github.io/app-support/
- https://justpeca.github.io/app-support/warefox/
- https://justpeca.github.io/app-support/warefox/support.html
- https://justpeca.github.io/app-support/warefox/privacy.html
